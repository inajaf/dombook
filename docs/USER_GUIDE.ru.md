# Руководство пользователя ДомБук

ДомБук — система бронирования для владельцев домов отдыха, коттеджей и отдельных арендных домов. Она рассчитана на одного администратора и объединяет объекты, календарь, гостей, оплату, депозиты, питание и резервные копии в одном простом интерфейсе.

## 1. Установка и запуск

### macOS

1. Скачайте `.dmg` или `.zip` для macOS со страницы GitHub Release.
2. Перенесите **ДомБук** в папку «Программы» и откройте приложение.
3. Публичная сборка не подписана Apple. Если macOS блокирует первый запуск, нажмите по приложению правой кнопкой и выберите **Открыть** либо разрешите запуск в **Системные настройки → Конфиденциальность и безопасность**.

### Windows

1. Скачайте установщик или portable `.exe` со страницы GitHub Release.
2. Запустите установщик либо откройте portable-версию без установки.
3. Публичная сборка не подписана сертификатом. Windows SmartScreen может показать предупреждение; выбирайте **Подробнее → Выполнить в любом случае** только для файла из официального релиза ДомБук.

### Web-версия

1. Скачайте и распакуйте `DomBook-…-web.zip`.
2. Запустите папку `web` через любой статический сервер, например:

   ```bash
   python3 -m http.server 8080 --directory web
   ```

3. Откройте `http://127.0.0.1:8080/`.

Web-версия хранит данные в локальном хранилище текущего браузера. Очистка данных браузера удалит их, поэтому регулярно экспортируйте JSON-backup. Desktop-версии используют локальную SQLite-базу и рекомендуются для постоянной работы.

## 2. Первичная настройка

1. Откройте раздел **Объекты**.
2. Если в одной локации находится несколько коттеджей, нажмите **Добавить дом отдыха** и укажите название и адрес.
3. Включите питание, если у дома отдыха есть кухня или ресторан.
4. Раскройте дом отдыха и добавьте каждый отдельно сдаваемый коттедж через **Добавить коттедж**.
5. Независимый арендный дом добавляйте через **Добавить отдельный дом**.

У каждого коттеджа или дома свои вместимость, цена за ночь, возвратный депозит, время заезда и выезда. Для каждого объекта ведётся отдельный календарь.

## 3. Создание брони

1. Нажмите **Новая бронь** либо свободный `+` в календаре.
2. Выберите дом и даты.
3. Укажите имя, телефон, количество взрослых и детей.
4. Отдельно введите предоплату за бронь и возвратный страховой депозит.
5. Выберите статусы брони и депозита.
6. Если питание включено, введите общую сумму завтрака, обеда или ужина для каждого дня. Указывается сумма за всю группу, а не стоимость одной порции.
7. Проверьте калькуляцию и сохраните бронь.

Проживание считается по формуле `количество ночей × зафиксированная цена ночи`. Предоплата уменьшает остаток к оплате. Возвратный депозит учитывается отдельно и не считается выручкой за проживание.

## 4. Ограничения бронирования

- Новый заезд можно создать максимум за 21 день вперёд.
- Одна бронь может длиться не более трёх календарных месяцев.
- Занятые ночи считаются от даты заезда до даты выезда, не включая сам день выезда.
- Активные брони одного дома не могут пересекаться.
- Количество гостей не может превышать вместимость дома.
- Даты рассчитываются в часовом поясе `Asia/Baku`.

## 5. Досрочный выезд

Откройте активную бронь и выберите **Досрочный выезд**. Укажите фактическую дату и способ расчёта:

- **Только использованные ночи** пересчитает проживание и уберёт питание с освобождённых дат.
- **Сохранить полную стоимость** освободит будущие ночи в календаре, но оставит исходную сумму проживания.

Если предоплата стала больше нового итога, ДомБук покажет сумму возврата клиенту.

## 6. Календарь и список бронирований

- Нажмите свободную ячейку, чтобы открыть форму с уже выбранными домом и датой.
- Нажмите занятую ячейку, чтобы отредактировать существующую бронь.
- Фильтры показывают активные брони, долги или депозиты.
- Отменённые и завершённые брони остаются в истории. Полное удаление доступно только для завершённых или отменённых записей.

## 7. Backup и расположение данных

В разделе **Настройки** отображаются путь к базе и папка резервных копий.

- Desktop: кнопка **Создать backup** создаёт проверенную копию SQLite с SHA-256 checksum.
- Web: кнопка **Создать backup** скачивает JSON-файл с данными браузера.

Создавайте backup перед крупными изменениями и копируйте важные файлы на другой диск или в облако. Облачная папка должна использоваться как резервная копия, а не как рабочая SQLite-база.

## 8. Язык

Откройте **Настройки → Язык приложения** и выберите Русский, Azərbaycan или English. Выбор сохраняется для следующего запуска.

## 9. Решение проблем

- **Дом отдыха пустой:** раскройте его и нажмите **Добавить коттедж**.
- **Дата недоступна:** проверьте лимит 21 день, максимальную длительность три месяца и пересекающиеся брони.
- **Питание недоступно:** включите кухню/ресторан у дома отдыха.
- **Объект пропал:** включите **Показывать архивные** и восстановите его.
- **Пропали данные Web-версии:** было очищено хранилище браузера либо открыт другой профиль; используйте последний экспортированный JSON-backup.
