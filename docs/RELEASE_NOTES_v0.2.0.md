# DomBook 0.2.0

DomBook 0.2.0 is the first public multi-platform release for owners who manage resorts, cottages and standalone rental houses.

## Highlights

- clickable 14-night availability calendar;
- resorts containing independently bookable cottages;
- standalone rental houses;
- reservation overlap and capacity protection;
- separate accommodation, prepayment, outstanding balance and refundable deposit accounting;
- breakfast, lunch and dinner totals for every booked day;
- early checkout with automatic calendar release and configurable recalculation;
- 21-day advance booking limit and three-calendar-month stay limit;
- Russian, Azerbaijani and English interface;
- local SQLite database and verified backups in the desktop editions;
- persistent browser storage and downloadable JSON backups in the Web edition;
- refreshed responsive design, motion and compact macOS Dock icon.

## Downloads

- macOS DMG and ZIP for Intel and Apple Silicon;
- Windows installer and portable executable for x64;
- Linux AppImage and DEB for x64;
- Web ZIP for any modern browser.

The public desktop binaries are not code-signed. Follow the first-launch instructions in the user guide if macOS Gatekeeper or Windows SmartScreen displays a warning.

## Data safety

Desktop databases stay on the local computer. Web data stays in the current browser profile. Create backups regularly and keep an additional copy on another disk or trusted cloud storage.
