# ДомБук Desktop

Кроссплатформенная локальная система бронирования домов и коттеджей.

## Возможности первого MVP

- dashboard и кликабельный календарь занятости;
- CRUD домов отдыха: создание, редактирование, архивация и восстановление;
- CRUD сдаваемых объектов: коттеджи внутри дома отдыха и отдельные дома;
- CRUD бронирований с защитой от пересечений;
- отмена активных броней и безопасное безвозвратное удаление завершённых или отменённых броней;
- автоматический расчёт проживания по числу ночей и цене объекта;
- отдельный учёт стоимости, предоплаты и страхового депозита;
- локальная SQLite-база;
- ручные резервные копии;
- сборки для macOS, Windows и Linux.

## Запуск

```bash
npm install
npm start
```

## Проверка

```bash
npm test
npm run test:smoke
```

## Где хранится база

В production база `dombook.sqlite` создаётся в системной директории `userData`
Electron. В режиме разработки путь выводится на экране «Настройки».

## Как устроены объекты

`Дом отдыха` — группа с общим названием и адресом. Внутри него владелец
создаёт несколько коттеджей, и каждый получает собственный календарь, цену и
депозит. `Отдельный дом` создаётся без группы и также бронируется независимо.

Отдельный визуальный план desktop-версии находится в
`.lavish/desktop-design-plan.html`.

## Сборка

```bash
npm run build:mac
npm run build:win
npm run build:linux
```

Надёжнее собирать каждый установщик на соответствующей ОС через CI:
macOS — на macOS, Windows — на Windows, Linux — на Linux.
